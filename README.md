# herriabihotzean-prieresbasques

Dépôt des prières usuelles de Herria Bihotzean.

## Fonctionnement
- index bilingue français / basque ;
- l'index conserve sa langue pendant la navigation ;
- chaque page de prière s'ouvre systématiquement en basque ;
- le bouton Frantsesez affiche la traduction française sans changer la langue mémorisée de l'index ;
- retour à l'index dans la langue précédemment sélectionnée ;
- une seule piste audio basque par page, audio/001.mp3 à audio/007.mp3 ;
- PDF attendu : othoitzeko-liburua.pdf.

## Anomalie dans les fichiers fournis
`messe.docx` est strictement identique à `meza.docx` et contient le texte basque. La section française de la page Sainte Messe est donc volontairement laissée en attente du véritable fichier français.
